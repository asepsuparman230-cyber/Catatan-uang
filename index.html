Backup & pengaturan

Backup manual

Ekspor file backup secara berkala dan simpan di Files, iCloud Drive, atau komputer. File backup berisi seluruh catatan utang/piutang dan transaksi kas.

Informasi penyimpanan

Data tersimpan di browser/perangkat ini. Menghapus data Safari atau data situs dapat menghapus catatan. Backup bukan sinkronisasi otomatis.

Catatan versi sebelumnya

Jika aplikasi V1 pernah digunakan pada alamat GitHub Pages yang sama di iPhone ini, data lama dengan kunci penyimpanan yang sama akan dibaca dan dipertahankan.
